# Sirio Pump WiFi

Відкрита прошивка та веб-інтерфейс для частотного перетворювача насоса **Italtecnica Sirio** —
заміна пропрієтарного Wi-Fi-модуля **WiNET** власною прошивкою на **ESP8266** із сучасною
веб-мордою українською. Містить повний реверс-інжиніринг внутрішнього UART-протоколу **J12**
між модулем і контролером дисплея (ATmega324PA).

🇬🇧 English version: [README.en.md](README.en.md)

---

## ⚠️ Застереження

- Це **незалежний аматорський проєкт**, не пов'язаний з Italtecnica чи Net Software і не
  схвалений ними. «Sirio» і «WiNET» належать їхнім власникам.
- Частотник керує насосом на **мережевій напрузі** — ризик ураження струмом і пошкодження
  обладнання. Усі роботи — **на власний ризик**, лише якщо розумієш, що робиш.
- **Вендорські матеріали не включені** (прошивка WiNET, стокові веб-файли модуля, PDF-мануали
  Sirio) — з міркувань авторського права.
- **Перед прошивкою зніми повний бекап** флеша модуля — так зможеш у будь-який момент повернути
  заводську прошивку WiNET.

## Що це і навіщо

Насос Sirio має роз'єм для фірмового Wi-Fi-модуля WiNET (хмара + застосунок). Модуль часто
недоступний у продажу, прив'язаний до хмари виробника, а його веб-інтерфейс застарілий.

Проєкт вирішує це так:

1. **Реверс протоколу J12** — як модуль спілкується з контролером частотника по UART.
2. **Своя веб-морда** — сучасна, адаптивна, українською (панель, параметри з поясненнями,
   журнал помилок, налаштування Wi-Fi і статичного IP).
3. **Своя прошивка ESP8266** — повністю замінює WiNET: тримає веб-морду, говорить із
   частотником по J12, працює локально без хмари, оновлюється по Wi-Fi (OTA).

## Залізо

| Компонент | Деталі |
|---|---|
| Частотник | Italtecnica Sirio (Universal), плата дисплея `IN10_100314` з МК **ATmega324PA** |
| Роз'єм модуля | **J12**: `1` TXD1, `2` RXD1, `3` +5 В, `4` GND (UART1 контролера + живлення) |
| Wi-Fi-модуль | WiNET = **ESP-WROOM-02** (ESP8266EX, 4 МБ), з перетворювачем рівнів 5 В↔3.3 В до J12 |

## Протокол J12 (реверс)

Повний опис — [docs/J12_PROTOCOL.md](docs/J12_PROTOCOL.md). Стисло:

- **19200 8N1, 5 В логіка.** Кадр фіксовано 7 байтів:
  `AA <dir> <op> <d0> <d1> <d2> <csum>`, де `csum = (сума перших 6 байтів) & 0xFF`.
  `dir=0xFF` — майстер→ATmega (запити/команди), `dir=0xFE` — відповідь ATmega.
- **Читання:** майстер шле `AA FF <op> 00 00 00`, ATmega віддає один із **10 статус-регістрів**
  (0x21–0x26, 0x41, 0x45–0x47) — уставка, струм, частота, температури, прапорці, лічильники,
  журнал помилок. Інших регістрів немає; параметри меню модуль тримає у власному кеші.
- **Команди:** `0x32`/`0x33` — крок параметра ±1 (індекс у `d2`), `0x34` — старт/стоп.

Реверс зроблено пасивним сніфом шини + активним скануванням (модуль-емулятор на ПК) і
звіркою з HTTP-API стокового модуля.

## Прошивка — `firmware/`

PlatformIO, ESP8266 (Arduino core). Один файл [src/main.cpp](firmware/src/main.cpp).

- **Веб-сервер** із усіма `/ajax`-ендпоінтами, сумісними з нашою мордою.
- **Майстер J12** — опитує частотник і виконує команди (порт еталонного `sirio_master.py`).
- **Веб-морда вшита в PROGMEM** ([src/webui.h](firmware/src/webui.h), генерується
  [make_webui.py](firmware/make_webui.py) з `webui/app/index.html`).
- **Wi-Fi:** режим STA (під'єднується до твоєї мережі) + **завжди активна резервна точка
  доступу** `Sirio-xxxxxx` (пароль за замовчуванням `siriopump` — зміни його).
- **OTA через браузер:** сторінка `/update` (логін `admin`, пароль = PIN, типово `1230`) —
  усі наступні оновлення по Wi-Fi, без паяння.
- **Налаштування** (Wi-Fi, статичний IP, параметри) — в EEPROM, переживають OTA.

### Збірка
```bash
cd firmware
pio run                 # firmware.bin
```

### Заливка (перший раз — по дротах)
ESP-WROOM-02, FT232 **на 3.3 В**, download-режим (`IO0`→GND на старті):

| FT232 | ESP |
|---|---|
| TX | RXD (IO3) |
| RX | TXD (IO1) |
| GND | GND |
| — | EN → 3V3 |
| — | IO0 → GND (на час прошивки) |

```bash
esptool --port COMx --before no-reset --after no-reset write-flash 0x0 firmware/.pio/build/esp_wroom_02/firmware.bin
```
Потім зняти `IO0` з GND, встановити модуль у J12, перезапустити. З'явиться точка `Sirio-xxxxxx`
→ під'єднатись (`siriopump`) → відкрити `http://192.168.4.1` → налаштувати Wi-Fi.

### Наступні оновлення — по Wi-Fi
Браузер → `http://<ip>/update` (admin / PIN), або
`curl -F "image=@firmware.bin" http://<ip>/update -u admin:1230`.

## Веб-морда — `webui/app/`

Один самодостатній `index.html` (без зовнішніх залежностей), українською, адаптивний:

- **Панель** — тиск, уставка, стан, струм/частота/напруга/температури, напрацювання, старт/стоп, ± уставки.
- **Параметри** — усі користувацькі й розширені параметри; кнопка **«і»** з описом і значенням
  за замовчуванням (із мануала), **поле вводу** значення з автокроком (бо протокол уміє лише ±),
  режими вибираються списком.
- **Журнал** — поточна аварія з розшифровкою, лічильники помилок E0–E13, журнал подій.
- **WiFi** — скан мереж, підключення, статичний IP.

### Розробка морди без прошивання
[sirio_web.py](sirio_web.py) — локальний дев-сервер: віддає морду й проксить `/ajax` на реальний
**стоковий** модуль (обхід CORS). Так морду можна «вилизати» на живому апараті до заливки.

## Інструменти реверсу (Python)

| Файл | Призначення |
|---|---|
| `sirio_uart_scan.py` | Сніфер UART + визначення швидкості, розбивка на кадри |
| `sirio_api.py` | Клієнт HTTP-API стокового модуля (оракул для розмітки шини) |
| `sirio_decode.py` | Пошук відомих полів у захоплених кадрах |
| `sirio_master.py` | ПК-майстер J12 (еталон протоколу; читання/керування з ПК) |
| `sirio_probe.py` | Скан усіх регістрів ATmega (майстер-режим) |
| `sirio_capture_cmd.py` / `sirio_capture_read.py` | Лов командних кадрів при тригері HTTP |
| `capture_boot.py` | Захоплення обміну під час завантаження модуля |
| `sirio_web.py` | Дев-проксі для морди |
| `fetch_stock_ui.py` | Витяг сторінок стокового модуля (для вивчення) |

Потрібні: Python 3, `pyserial`; для роботи з флешем — `esptool`.

## Відкат на заводську прошивку

Якщо зняв повний бекап флеша перед заливкою:
```bash
esptool --port COMx --before no-reset --after no-reset write-flash 0x0 winet_full_4MB.bin
```
(Бекап у репозиторій не входить — зніми власний зі свого модуля.)
